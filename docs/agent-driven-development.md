# エージェント活用開発フロー

Claude Code や Codex などのエージェントを活用して開発を進める際の推奨フローをまとめる。

**これは推奨フローであり、エージェントに強制するものではない。** タスクの規模や内容に応じて、一部の手順を省略したり順序を入れ替えたりしてよい。

## 推奨フロー

1. **プラン作成（高品質モデル）**
   Fable 5 / Opus 4.8 など、品質を優先したモデルで `plans/` ディレクトリにプランを作成する。
2. **実装（安価なモデル）**
   Sonnet 5 など、コストを優先したモデルで、作成したプランをもとに実装する。
3. **Draft PR の作成**
   実装が完了したら、まず Draft の状態で PR を作成する。
4. **詳細レビューの実施**
   `.agents/skills/pr-review-report/SKILL.md` のレビュースキルを使って詳細レビューを実施する。
5. **レビュー依頼**
   レビューが完了したら Draft を解除し、レビューを依頼する。

## `plans/` ディレクトリ

- 用途: 実装前の設計やタスク分解を記録する場所。実装に着手する前に、対応方針や作業手順を整理しておく。
- 命名規則: `plans/<issue番号>-<概要>.md`（例: `plans/2-agent-driven-development.md`）
- 対応する Issue が完了した後もプランは削除せず、経緯の記録として残す。
