# エージェント活用開発フロー

Claude Code や Codex などのエージェントを活用して開発を進める際の推奨フローをまとめる。

**これは推奨フローであり、エージェントに強制するものではない。** タスクの規模や内容に応じて、一部の手順を省略したり順序を入れ替えたりしてよい。

## 推奨フロー

1. **プラン作成（任意）**
   必要に応じて、現在の worktree の `plans/` ディレクトリに設計やタスク分解を一時ファイルとして整理する。使用するモデルや作成方法は、タスクの規模と内容に応じて選択する。
2. **実装**
   作成したプランを参照しながら実装する。プランの内容を長期的に残す必要がある場合は、Issue、PR、関連ドキュメント、またはソースコードへ反映する。
3. **Draft PR の作成**
   実装が完了したら、まず Draft の状態で PR を作成する。
4. **詳細レビューの実施**
   `.agents/skills/pr-review-report/SKILL.md` のレビュースキルを使って詳細レビューを実施する。
5. **レビュー依頼**
   レビューが完了したら Draft を解除し、レビューを依頼する。

## `plans/` ディレクトリ

- 用途: 実装前の設計やタスク分解を整理する一時ファイル置き場。必要なときだけ現在の worktree に作成する。
- Git 管理: `plans/.gitkeep` 以外は Git 管理対象外であり、プランはコミットしない。
- 永続化: プランに含まれる判断や経緯を残す必要がある場合は、対応する Issue、PR、関連ドキュメント、またはソースコードへ反映する。
